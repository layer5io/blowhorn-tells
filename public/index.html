One message out, many ears in.

Tells is a free check from the Blowhorn team. It shows what websites can read about your browser.

What this page sends

  • When this page opens, it runs checks in your browser and sends the readings to this site's server, which scores them and sends the result back.
  • This site keeps no copy and no logs.
  • Two outside services see your IP address: the server sends it, and nothing else, to ipapi.is to spot proxies and VPNs, and the WebRTC check asks Google's public STUN server for your address.
  • This page carries Google Analytics, the same tag as blowhorn.ai, so Google sees the visit and this page's address. There is no consent banner; this list is the disclosure.
